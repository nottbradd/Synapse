Latin assets were copied from the approved Synapse typography reference. Extended Latin assets were obtained from the corresponding Google Fonts CSS distribution on 2026-11-15:

- https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwSGFWfOw.woff2
- https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggmxSuXd.woff2

Both families include Latin Extended and IPA ranges. Segoe UI and the system sans-serif provide glyph fallbacks outside the bundled coverage. KaTeX retains its own specialised fonts. No fonts are fetched at runtime.
